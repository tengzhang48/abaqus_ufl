# AI Skills

This directory contains reusable AI-agent skills distilled from the
`abaqus_ufl` examples and development notes.

## Available Skills

- `abaqus-ufl/` - operational guide for developing, reviewing, validating, and
  debugging `abaqus_ufl` UMAT/UEL models.

## Use

The skill ships inside this repository so any AI agent can use it directly. To
install it in an environment with a writable skills directory, copy:

```text
ai_skills/abaqus-ufl/
```

into that environment's skills directory.

Agents can also read `ai_skills/abaqus-ufl/SKILL.md` directly when working in
this repository.
